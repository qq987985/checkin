签到地址在哪里获取？

网页签到（如金山灵犀 / WPS）

  1. 在电脑浏览器登录账号，打开能手动签到的页面。
  2. 打开开发者工具（F12；Mac 可按 ⌥⌘I），切换到 Network（网络），选中 Fetch/XHR。
  3. 保持网络面板打开，手动点击一次「签到」，查看这次新增的请求。若看不到请求，切回 All（全部）。
  4. 打开对应请求，在 Headers（请求头）→ General（常规）中复制 Request URL，粘贴到上方；把 Request Method 选为相同的方法。
  5. 在 Request Headers 中查看 Cookie、Authorization 或其他 Token 请求头，填写下方验证方式和凭据；如有 Payload（请求载荷），在高级配置中填写请求体。

豆包 App 签到

需要从手机 App 实际点击签到时的网络请求获取 URL、请求头和请求体；电脑端豆包首页或火山方舟模型 API 地址不能代替它。可使用支持该设备的网络调试工具查看自己账号的签到请求。若无法获取请求，暂时无法配置自动签到。

如果请求包含动态签名、设备校验或一次性参数，复制地址和 Token 仍可能无法重放，需要专门适配。

可右键网页请求 → Copy → Copy as cURL，便于核对地址、方法、请求头和请求体。完整 cURL 可能含登录凭据，请只在本机保存和填写。
